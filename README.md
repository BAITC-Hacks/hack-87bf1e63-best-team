## Калькулятор

Калькулятор с веб-интерфейсом. Логика вычислений вынесена в отдельный модуль
без обращений к DOM, поэтому её можно тестировать и переиспользовать.

### Запуск

Откройте `index.html` в браузере — сборка не нужна, зависимостей нет.

```bash
python3 -m http.server 8000   # затем http://localhost:8000
```

### Тесты

```bash
npm test
```

### Возможности

- Сложение, вычитание, умножение, деление, остаток от деления
- Цепочка операций: `2 + 3 * 4 =` считает по шагам и даёт `20`
- Смена знака (`±`), проценты (`%`), backspace, сброс (`C`)
- Деление на ноль показывает ошибку вместо `Infinity`
- Сглаживание погрешности плавающей точки: `0,1 + 0,2 = 0,3`
- Управление с клавиатуры: цифры, `+ - * / %`, `.` или `,`, `Enter`/`=`, `Backspace`, `Esc`

### Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка калькулятора |
| `src/calculator.js` | Ядро: состояние и операции, чистые функции |
| `src/app.js` | Связь ядра с DOM, обработка мыши и клавиатуры |
| `src/styles.css` | Оформление |
| `test/calculator.test.js` | Тесты ядра (`node --test`) |
